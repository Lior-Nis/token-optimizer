## Install from a checkout

```bash
git clone --depth 1 https://github.com/alexgreensh/token-optimizer.git
cd token-optimizer
bash install.sh --devin --dry-run
bash install.sh --devin
python3 -I "$HOME/.config/devin/token-optimizer/plugin/devin_doctor.py" --probe
```

POSIX and Python are required; native Windows is refused. WSL uses the Linux home. The installer owns only `~/.config/devin/skills/token-optimizer-output/` and the private `~/.config/devin/token-optimizer/plugin/` payload. Host config, foreign skills and hooks remain unchanged. Absolute XDG/namespaced home overrides must remain inside HOME.

Installation records consent: filtering/passthrough/recovery may show confidential capture contents to Devin/model context; numeric metrics remain local. A raw passthrough removes its capture after delivery; a compressed result keeps its capture for recovery until you delete it or uninstall with `--purge`. Other imported hooks may create their own copies. No auto-approval fields are installed.

Run `devin skills show token-optimizer-output` to check the selected source and `Triggers: user`. A same-named project skill can shadow the global skill. Doctor's probe is local, not a live Devin model test.

## Desktop: Devin Local

Install in the same POSIX HOME/environment used by Desktop's local agent. Select Devin Local, enabling it in Devin User Settings > Agents and restarting if needed. Team/admin access may also be required; Restricted Mode disables agents. Open Customizations from the new-tab menu or the right-click menu on a Devin Local session in the agent sidebar to verify the selected user skill, then invoke `/token-optimizer-output` explicitly. Cascade and other ACP agents are not covered. Desktop loading/execution have not been live-tested.

For loader overrides, WSL boundaries, diagnostics and current limitations, see [the full Desktop contract](/platforms/devin/#desktop-devin-local-contract) and the repository's `devin/README.md`. [Primary Desktop contract](https://docs.devin.ai/desktop/devin-local).

## Capture workflow

Read the repository's `devin/README.md` for the exact prepare, native redirection, seal and filter sequence. Use new pre-created 0600 files for each completed foreground command; never background the producer or run interactive input through capture. Do not display full successful output before filtering. Small output should skip this workflow because orchestration can outweigh reduction.

## Remove

```bash
bash install.sh --devin --uninstall
bash install.sh --devin --uninstall --purge
```

Uninstall removes only unchanged owned files. Purge additionally removes metrics/SQLite sidecars, private salt, consent and stored captures. Changed installed files are preserved and removal is refused. To stop activation manually, move only your edited `token-optimizer-output` skill directory out of Devin's search paths. See [Devin limits](/platforms/devin/).
